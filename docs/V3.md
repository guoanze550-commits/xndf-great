下载 Actions 的 **The-Permitted-World-V3-Web-Preview** Artifact，完整解压，使用Node24运行 `node serve-preview.cjs`，在浏览器打开终端显示的地址。预编译包不需要 `npm install`，音乐与模型均本地。预览包实际运行/下载链接在PR最终验收中记录。

本地：切换本分支，Node24下执行 `npm ci`、`npm run assets`、`npm run dev`。浏览器按终端地址访问。桌面沿用 `npm run build` / `npm run desktop`，本轮不反复制作Mac安装包。

## 连续冒险

1. **雪境初醒**：A→西阶→B→东廊→上庭→C，原三机构、五次跨越、误导及解法保留。进入暖光门，光幕遮蔽切关。
2. **断桥迷城**：旋转断桥+助跑越隙；压力板供能的14秒冰桥；轨道平台水平/垂直载人、巨桥锁定与第二次跳跃。落在终点后建筑再升起2.2米，角色随台抬升并走入高层入口，自动进入第三关。
3. **倒悬之境**：真实摄影机投影重合才许可第一条路；压力板联动升降台；上层先释放配重，再组合石环、角度、高度与20秒冰路，助跑越过最后缺口。重组后环绕运镜回到可操作角度；第三关入门才触发最终界面。

切关由实际到达/落地、门口行走完成、遮蔽完成和新镜头就绪共同驱动，不能凭等待时间跳关。失败返回当前检查点；新场景构建失败恢复上一安全点。新场景各缓存一次，共用一个渲染器、角色与音乐实例，重开不重复累积场景。

## 机制与边界

`levels.ts` 配置挑战、目标与运动参数；`Locomotion` 处理加速、摩擦、重力、起跳准备、空中运动、台面阻挡和落地；`AdventureRules` 共用两关的桥面/限时/平台/配重状态；`Campaign` 管理事件式连续冒险。移动发生在有宽度和高度的桥面走廊，碰撞定义与可见路径共享坐标映射。空间错位段沿真实三维连接面连续走过，不直接传送角色。

第三关许可由**当前真实摄影机矩阵**测量两个世界端点的屏幕距离，不信任Q的选项值。平移/缩放不改变许可，侧观和电影环绕角度不能伪造连接。环绕时锁定行动，实际镜头方向和目标归位后恢复输入。

角色沿用原风衣、围巾、帽子和比例，以独立膝/肘和距离驱动程序化步态表现Idle/Walk/Run/JumpPreparation/Jump/Land/Fall。尚需人工检查动作观感和足部接触自然度。

新建筑采用承重墩、分层檐带、深景拱廊、配重机构与砌石大环，保留原石材、积雪、水、薄雾和灯光资源。静态结构、桥板、石环细节使用Instancing。低帧率自动关闭Bloom和动态阴影，降低反射/雪开销；新关卡极低帧率时限制单帧模拟步长以保证输入和计时公平，不将软件渲染结果当作Apple Silicon 60FPS证明。
